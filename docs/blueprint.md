# **App Name**: NutriCode

## Core Features:

- QR Code Scanning: Displays nutritional information, ingredients, and allergen warnings when users scan a QR code.
- Personalized Nutrition Profiles: Allows users to customize the displayed information based on dietary restrictions and preferences.
- Multi-Language Support: Supports multiple languages to cater to a global audience.
- Sustainability Tracking: Displays environmental impact scores and sourcing information for conscious consumers.
- Backend Language: Ensure backend is in python

## Style Guidelines:

- Primary color: Vibrant green (#6AD58B) to evoke health, nature, and freshness, aligning with the app's focus on nutrition and sustainability.
- Background color: Light, desaturated green (#E5F5E9) provides a clean and airy feel, ensuring readability and reducing visual fatigue.
- Accent color: Soft, muted yellow (#F4E27B) as an analogous color to the green for CTAs and highlights, complementing the green while creating a warm and inviting contrast.
- Clean and modern typography for readability.
- Simple, intuitive icons for easy navigation.
- Clean, card-based layout for clear information hierarchy.
